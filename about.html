ABOUT OUR PROJECT

Student Study Planner

A simple website to help students organise assignments and study deadlines.

Start planning

Our purpose

The planner gives students one place to add assignments, set priorities and track progress.

SDG 4

This project supports the aim of Quality Education by helping students organise independent learning. Its effect on grades has not been measured.

How to use it

  1. Open My Tasks.
  2. Add a title, subject, deadline and priority.
  3. Edit or complete your assignments.
  4. Check Calendar and Progress.

Your saved tasks

This version saves tasks in your current browser on this device. It does not use accounts or a shared database. Clearing browser data can remove saved tasks.

Built with HTML, CSS and JavaScript as a group website project.
